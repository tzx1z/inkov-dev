solution

Решение

Инструкции по установке Prosody 13. В них описаны все этапы настройки: DNS и SRV-записи, wildcard-сертификат Let's Encrypt через API Cloudflare, звонки через coturn, архив сообщений, обмен файлами и push-уведомления для мобильных клиентов.

Одна из инструкций описывает сервер, на котором уже работает 3x-ui: XMPP и Xray REALITY принимают соединения на одном порту 443, HAProxy распределяет их по SNI.

Каждый шаг проверен на конкретных версиях пакетов, после шагов указан ожидаемый вывод и команды отката. Инструкции учитывают ограничения сети у российских хостеров и доступны на русском и английском.

stack

Стек

Prosody 13, HAProxy, Xray REALITY и 3x-ui, coturn, Let's Encrypt, API Cloudflare, DNS SRV-записи. Инструкции для Ubuntu 22.04, 24.04 и 26.04.
