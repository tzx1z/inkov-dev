Политика конфиденциальности расширения InkVault

Расширение InkVault Password Manager (далее - расширение) разрабатывает Евгений Иньков. Здесь описано, что происходит с вашими данными при работе расширения.

Что собирает разработчик

Ничего. В расширении нет аналитики, телеметрии, отчетов о сбоях и рекламы, оно не подключается к серверам разработчика.

vault

Где ваши данные

Логины хранятся в вашем хранилище. Оно шифруется на устройстве ключом из мастер-пароля (Argon2id, XChaCha20-Poly1305) и синхронизируется через XMPP-сервер, который вы выбрали. Сервер хранит только шифротекст. Мастер-пароль не покидает устройство и нигде не сохраняется.

browser

Что хранится в браузере

Учетная запись хранилища (соль и обернутые ключи, без секретов), зашифрованная копия хранилища, токен входа в учетную запись XMPP, id устройства, адрес сервера и настройки расширения. Расшифрованное хранилище есть только в памяти, пока хранилище открыто, и удаляется при блокировке.

pages

Страницы сайтов

Расширение читает поля входа на странице, только когда вы просите их заполнить: кнопкой "Заполнить", горячей клавишей или из контекстного меню. Оно заполняет один логин и пароль и ничего со страницы не сохраняет и не отправляет.

clipboard

Буфер обмена

Скопированный пароль удаляется из буфера обмена через 30 секунд.

third_parties

Третьи лица

Данные отправляются только на ваш XMPP-сервер, в зашифрованном виде и по TLS. Они не продаются и никому не передаются.

При установке Firefox запрашивает согласие на передачу данных аутентификации: речь о логинах, которые уходят зашифрованными сквозным шифрованием, и о данных входа XMPP, в обоих случаях только на ваш XMPP-сервер. Разработчик их не получает.

При первом входе расширение использует SCRAM, и сервер получает только доказательство, вычисленное из пароля XMPP. Сам пароль уходит по TLS, только если сервер не поддерживает SCRAM.

Если адрес сервера не указан, расширение запрашивает https://<домен вашего JID>/.well-known/host-meta, чтобы его найти. Данных из хранилища в запросе нет.

deletion

Удаление данных

"Удалить хранилище" удаляет хранилище с сервера и из браузера. При удалении расширения браузер удаляет все данные, которые оно сохранило.
